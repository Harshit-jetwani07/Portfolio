# Harshit Jetwani Portfolio

Personal portfolio website for showcasing skills, projects, and contact links.

## Sections

- Hero introduction
- About me
- Skills
- Featured projects
- Contact links

## Project Structure

```text
Portfolio/
├── assets/
│   ├── images/
│       ├── photo.jpeg
│   └── resume/
│       └── Harshit_Jetwani_Resume.pdf
├── index.html
├── style.css
├── script.js
├── README.md
└── .gitignore
```

## Run Locally

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8765
```

Then visit:

```text
http://127.0.0.1:8765
```
