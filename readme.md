# Harshit Jetwani Portfolio

A personal portfolio website for showcasing my profile, skills, resume, and featured projects. The site has a dark gaming-inspired interface with neon HUD cards, animated particles, a rotating hero orbit, responsive project sections, and direct live links to my work.

## Live Portfolio

Portfolio link :(https://harshit-jetwani07.github.io/Portfolio/)

Portfolio repo: [Harshit-jetwani07/Portfolio](https://github.com/Harshit-jetwani07/Portfolio)

## Highlights

- Responsive portfolio built with HTML, CSS, and JavaScript.
- Gaming-style visual design with neon grid, scanline effect, glowing cards, and animated project reveals.
- Hero section with animated typing text and a rotating orbit effect around the profile image.
- Detailed project showcase with logos, stack details, feature bullets, tags, and live links.
- Resume, GitHub, LinkedIn, and email contact links.

## Run Locally

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8765
```

Then visit:

```text
http://127.0.0.1:8765
```
